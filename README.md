# Bean Scene - Coffee Shop Landing Page

A responsive landing page built as a training project. Layout taken from Figma Community.

Design by [Mohammed Jawed](https://www.figma.com/@thisuix571) - [Bean Scene Coffee Landingpage](https://www.figma.com/community/file/1201418433329014860/bean-scene-coffee-landingpage), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Coded by [Amelia-webb](https://github.com/Amelia-webb).

## Live demo
https://amelia-webb.github.io/bean-scene/

## Stack
- HTML5 - semantic markup
- CSS3 - Flexbox, Grid, media queries
- JavaScript - burger menu

## Run locally
Open `index.html` in a browser, or use Live Server in VS Code.
